# Выпуски AR — приложение для Android (v5.0)

Нативное приложение на ARCore: полупрозрачный фундамент и колонна (пьедестал) в натуральную величину
поверх камеры, граница защитного слоя, привязка к печатной метке или посадка под крестик.

## Как получить APK
1. Загрузите всё содержимое этой папки в репозиторий GitHub (ветка `main`), включая папку `.github`.
2. Откройте вкладку **Actions** — сборка «Сборка APK» запустится сама (5–10 минут).
3. Готовый файл `VypuskiAR.apk` появится в разделе **Releases** репозитория.
4. Скачайте APK на телефон и установите (разрешите установку из браузера).

## Требования
Android 10+, поддержка ARCore («Сервисы Google Play для AR»).

## Метка
Файл `Metka_Vypuski_AR.pdf` печатается в масштабе 100 %. Ширину чёрного квадрата измерить линейкой
и вписать в приложение. Изображение метки — `app/src/main/assets/marker.png`.
